# Roadmap

High-level public milestones for ARP Restaurant. These are not implemented in the current bootstrap.

## 0.1 Foundation/domain

Canonical extension foundation and restaurant domain data (menus, categories, items, prices, opening hours) without assuming hardcoded public page paths.

## 0.2 Presentation/Mosaic

Frontend restaurant presentation. Mosaic Gallery remains an optional integration.

## 0.3 Simple direct ordering

Simple direct ordering that can run locally on the TYPO3 site without ARP.top.

## 0.4 Order confirmation

Order confirmation flow for direct orders.

## 0.5 ARP connector

Optional ARP.top operational connector. Local/free ordering remains usable without it.

## 1.0 Stable public release

First stable public release.
